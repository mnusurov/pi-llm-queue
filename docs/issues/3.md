## Acceptance criteria (must fix)

- [ ] **1. Serialisation survives turn 2+.** `release()`'s `{op:"ok"}` reply must not be
  consumed by the next `acquire`. `read()` matches replies to requests: `acquire` resolves
  only on `{op:"granted", queueKey, sessionKey}`; other messages are dropped, not buffered.
  Repro (from audit): acquire A → release A → acquire B → acquire A resolves instantly
  without a slot. Add a socket-seam test for this repro.
  (`src/lease-client.ts:116-121,132-135`, `src/daemon.js:93-96`)
- [ ] **2. No waiter hijack.** Multiple concurrent `acquire` calls from one client must not
  overwrite a single pending waiter; a queued `agent_start` plus an out-of-run request
  (compaction) must not wedge the session forever. Keep a list of pending waiters, deliver
  by match (same mechanism as fix 1). Add the audit repro test
  (`Promise.race([first, sleep(500)])` rejects).
  (`src/lease-client.ts:116-121`, `src/extension.ts:95,118`)
- [ ] **3. Esc while queued cancels.** Attach the abort listener **before**
  `await lease.acquire(...)`; the abort path sends `cancel` for the queued request (or
  closes the socket — the daemon drops queued waiters on disconnect, `src/daemon.js:141-145`).
  Update `docs/daemon-protocol.md` claims to match behaviour.
  (`src/extension.ts:95-97,72-79`)
- [ ] **4. Paths with spaces/non-ASCII work.** `decodeURIComponent(new URL(...).pathname)`
  for `DAEMON_PATH` and in `scripts/e2e-two-sessions.mjs:12`; a spawn `error` must not be
  swallowed silently (notify).
  (`src/extension.ts:21`, `src/lease-client.ts:52`)
- [ ] **5. `make e2e` passes on a stub endpoint** (new make target running
  `scripts/e2e-two-sessions.mjs`). If the agent environment cannot spawn real pi
  processes, this is a manual step for the maintainer — say so explicitly in the PR.
- [ ] `make test` and `make typecheck` green with the new tests.
